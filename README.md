# React kezdőapp

Egyszerű React + Vite projekt, magyar kezdőoldallal és kattintásszámlálóval.

## Indítás

```sh
npm install
npm run dev
```

Windows PowerShellben, ha az npm szkript futtatása tiltott, használd az `npm.cmd` parancsot.

## Build

```sh
npm run build
npm run preview
```

A kezdőoldal a `src/App.jsx`, a stílusok a `src/index.css` fájlban találhatók.
